A web-based Apartment Society Management System developed to digitize and simplify common society management activities such as flat management, resident management, maintenance bills, payments, complaints, and society expenses.

The application provides separate access for Administrators and Residents, with authentication and authorization implemented using Spring Security and JWT.

Technologies Used

Backend
Java
Spring Boot
Spring Data JPA
Spring Security
JWT (JSON Web Token)
REST APIs
PostgreSQL

Frontend
React
HTML
CSS
JavaScript

Features
Admin
Admin login with JWT authentication
Manage flats
Manage residents
Create and manage maintenance bills
View and record payments
Manage resident complaints
Manage society expenses
View society dashboard information
Access admin-protected APIs using role-based authorization

Resident
Resident login with JWT authentication
View own profile
View assigned flat information
View maintenance bills
View payment records
Raise complaints
View complaint status
Access only the information associated with the logged-in resident where applicable
